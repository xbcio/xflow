# @xflow/workflow-renderer

React Flow based canvas renderer, overlays and unknown-node fallback.

## Dependency constraints

- Depends on `@xflow/workflow-core`, `@xflow/workflow-provider`, `@xflow/node-registry`.
- Declares `react`, `react-dom` and `@xyflow/react` as peer dependencies (`@xyflow/react` optional for now).
- No API calls, no save/publish logic.
- No Umi runtime.
