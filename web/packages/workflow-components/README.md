# @xflow/workflow-components

Workflow-specific UI components reused by at least two applications. Not a generic design system.

## Dependency constraints

- Depends on `@xflow/workflow-core`, `@xflow/workflow-provider`, `@xflow/node-registry`, `@xflow/workflow-renderer`.
- Declares `react`, `react-dom` and `@xyflow/react` as peer dependencies (`@xyflow/react` optional for now).
- Does not wrap Ant Design base controls as a design system.
- No Umi dependencies.
