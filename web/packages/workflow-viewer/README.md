# @xflow/workflow-viewer

Viewer component package: read-only display and execution overlay.

## Dependency constraints

- Depends on `@xflow/workflow-core`, `@xflow/workflow-provider`, `@xflow/node-registry`, `@xflow/workflow-renderer`, `@xflow/workflow-components`, `@xflow/api-client`.
- Declares `react`, `react-dom`, `@xyflow/react`, `zustand`, `@tanstack/react-query` as peer dependencies (non-React peers optional for now).
- No Umi / Ant Design / ProLayout dependencies.
- Does not depend on `@xflow/workflow-editor`.
