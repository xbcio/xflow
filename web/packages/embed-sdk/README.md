# @xflow/embed-sdk

iframe embed SDK: `createWorkflowEditor` / `createWorkflowViewer`, postMessage protocol, CSP/origin validation.

## Dependency constraints

- Depends on `@xflow/workflow-editor` and `@xflow/workflow-viewer`.
- Usable from React and non-React hosts via iframe.
- No Umi / Ant Design / ProLayout dependencies.
