# @xflow/workflow-editor

Editor component package: instance store, command stack, palette, property panel, Monaco integration.

## Dependency constraints

- Depends on `@xflow/workflow-core`, `@xflow/workflow-provider`, `@xflow/node-registry`, `@xflow/workflow-renderer`, `@xflow/workflow-components`, `@xflow/api-client`.
- Declares `react`, `react-dom`, `@xyflow/react`, `@monaco-editor/react`, `zustand`, `@tanstack/react-query` as peer dependencies (non-React peers optional for now).
- No Umi / Ant Design / ProLayout dependencies.
- Does not depend on `@xflow/workflow-viewer`.
