# release/

This directory holds the repository's **tracked release record**.

| Path | What it is |
|---|---|
| `evidence-summary.json` | The current release evidence summary, generated by `make release-summary`. |

## Why it is here and not in `docs/`

`docs/design/RELEASE-GATES.md` is the *policy*: which gates exist, what they
prove, and what may not be claimed. This directory is the *record*: the frozen
output of one signed gate run, small enough to review in a diff and non-sensitive
enough to live in a public repository. Keeping them apart means "what we promise"
and "what we can show" are updated independently and cannot be confused.

## Why the file may be missing

`evidence-summary.json` is generated, not authored, and it is deliberately **not
committed as a placeholder**. Its presence means a signed gate run happened for
the `candidate_sha` it names. Its absence means no such record exists yet —
never that there is nothing to review.

Generate it with:

```sh
make test-g0-evidence-required REVIEWER="<name>" RE_RUNNER="<name>"
make release-summary
```

Every per-run artifact this summary is derived from is gitignored
(`test/integration/testdata/`); the summary is the only part of that evidence a
fresh clone receives.

The format is a documented contract:
[docs/references/release-summary-format.md](../docs/references/release-summary-format.md).
